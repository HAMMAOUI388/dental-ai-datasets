# Dental AI Dataset Tracker

This repository tracks the datasets collected and evaluated for dental X-ray and 3D tooth image analysis for deep learning training.

## 📁 Structure

- `datasets/` – Folder structure of downloaded datasets (sample only, real files stored elsewhere)
- `notes/` – Daily research notes and challenges
- `dataset-sources.md` – Links and info about each dataset
- `screenshots/` – Screenshots of dataset sources
